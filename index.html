Galeria obrazów

Wybierz folder na dysku, który traktujesz jak „images”. Pliki nie są wysyłane nigdzie – wszystko działa lokalnie w przeglądarce.

Konfiguracja filtrów

Zmiany są widoczne na żywo. Gdy wybierzesz „Własny obraz”, używany jest obraz z galerii.

GitHub (opcjonalnie)

Token z uprawnieniami do repo (np. `repo`). Przechowywany tylko w sesji.

Wysyła aktualnie wybrany obraz do folderu `images/` w wskazanym repo.
